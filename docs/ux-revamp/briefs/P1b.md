## Build (new folder `app/static/js/persist/`, styles in `app/static/css/persist.css`; tokens and `sf-` components only)
1. `sf.storage.ensurePersistent()` (extend `core/storage.js`): calls `navigator.storage.persisted()` then `persist()` when not yet granted; returns `'granted' | 'refused' | 'unsupported'`; never throws (Safari and headless may behave differently). Call it after every successful `saveClass` (the engine's `saveClassRecord` in `engine/transcribe.js` already calls `RunStore.saveClass(...)`: add ONE `.then(() => sf.storage.afterSave())` there, the only engine edit allowed in this step, in its own commit with a test, and re-check the 6 hashes).
2. Storage section in "Detalles técnicos": "Almacenamiento" with used space and quota from `sf.storage.estimate()` labelled "estimado" (bytes formatted MB or GB; if there is no estimate show only what the saved classes occupy, no bar and no percentage), and the persistence state in plain words. When refused: the calm notice "El navegador puede borrar tus clases guardadas si se queda sin espacio. Descarga una copia de las que quieras conservar." (an `sf-banner`, not red, no alarm). When granted: "Este navegador ha concedido almacenamiento persistente." Refresh after each save.
3. `sf.classes` helper (`persist/classes.js`): `list()` (saved classes from RunStore: done and partial runs with `name`, `savedAt`, `durationSec`, `sizeBytes`, `incomplete`), `remove(runId)` (uses `RunStore.deleteRun`), newest first. P3 will reuse it.
4. Storage-full handling: extend the danger toast from P1a with actions: "Gestionar clases" (opens a dialog listing the saved classes with name, date, duration and size and a "Borrar" button per class; deleting asks `sf.confirm` in danger style: "Se borrarán el audio y la transcripción de «name». No se puede deshacer.") and, for the current run, "Descargar copia" (point 5). Also change the toast body sentence "La transcripción sigue en marcha..." to "La transcripción no se pierde: puedes copiarla o exportarla." (true whether the run is still active or already finished).
5. "Descargar" backup (`persist/download.js`): `sf.classes.downloadAudio(runId)` saves the stored audio blob in its original format with a sensible extension (from the stored file name, else from the mime type: `audio/webm` webm, `audio/mp4` and `audio/x-m4a` m4a, `audio/mpeg` mp3, wav, ogg, flac; never `.wav` for something that is not WAV) and `sf.classes.downloadText(runId)` saves the transcript as .txt built from the STORED segments with the same clean-line format as `sf.transcript.toText()` (expose the formatting function of `model.js` so both use one implementation). Two separate buttons, because browsers may block a second automatic download. File names are the sanitized class name plus the extension.
