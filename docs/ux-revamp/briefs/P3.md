## Goal
After a reload or days later the student finds every saved class, opens it with its transcript and audio player, can rename or delete it, and sees how much space they use. This uses what earlier milestones stored and built: `RunStore` records (P1a: `name`, `fileName`, `sizeBytes`, `mimeType`, `durationSec`, `durationExactSec`, `savedAt`, `incomplete`, flat absolute-time `segments`, plus `audioBlob` and `chunkResults`), `app/static/js/persist/{classes,download,panel}.js` (P1b: `sf.classes.list()`, `remove(runId)`, `downloadAudio`, `downloadText`, the storage section), `sf.transcript` (model, `seedFromRecord`, `toText`, `formatText`), the reading view (`js/transcript/reader.js`), search (T2-c) and the docked player (`js/player/transcript-player.js`, `sf.transcriptPlayer.attach({blob, durationSec})`).

## Build (new `app/static/js/library/`, `app/static/css/library.css`; tokens and `sf-` components only; markup in `app/templates/index.html`)
1. Views and routing: the page has three views: home (start, recording, run: today's screens), `#viewClasses` (list) and `#viewClass` (an opened class). Hash routing (`#/clases`, `#/clases/<runId>`, `#/` for home) so the browser Back button and reloads work; one view visible at a time; on every view change move focus to that view's `h1` and announce the title politely. Header link "Mis clases" (a real link, current page marked `aria-current="page"`): it appears now, because the view exists. While a run is active or a recording is in progress, the link is disabled with an explanation ("Disponible cuando termine la transcripción" / when you stop recording); never navigate away from a live run.
2. List, following `A/classes.html`: heading "Mis clases" with a primary "Nueva clase" button (home), the storage summary (used space and the browser quota labelled "estimado"; no bar and no percentage when the browser gives no estimate; reuse `sf.storage.estimate()` and the P1b texts), the honest note that classes are stored in this browser only ("Guardado en este navegador. Estas clases no salen de tu dispositivo: si borras los datos del sitio o cambias de navegador, no estarán."), and the persist-refused calm notice from P1b when it applies. Rows newest first: name, date (Spanish long date), duration (mono), size, badge "Incompleta" for partial classes, actions Abrir, Renombrar, Borrar, and Descargar audio / texto (P1b functions). Empty state (guide's pattern): "Aún no tienes clases" with one sentence and the "Nueva clase" action. Data from `sf.classes.list()`; extend it only if a needed field is missing.
3. Open a class: from the stored `segments` (fallback for records saved before P1a, which have no `segments`: `sf.transcript.seedFromRecord(record)` from `chunkResults`) fill the transcript model and render the SAME reading view (title, file name, duration, counts, gap rows, incomplete banner, search, Copiar/Exportar) and attach the player with the stored audio and the stored duration (`durationExactSec` else `durationSec`, never the element's, Chrome WebM reports Infinity). Add `sf.transcript.loadClass(record)` in `transcript/model.js` if needed. Leaving the view detaches the player and revokes object URLs. Copy and Export from an opened class must produce exactly `toText()` of the stored segments.
4. Rename: inline row (as in the mockup: label "Nuevo nombre", Guardar, Cancelar; Enter saves, Escape cancels; trimmed, not empty, max length); saved with `RunStore.saveClass(runId, {name})` (merge, must not touch segments or audio). Failed save shows the P1a storage toast.
5. Delete: `sf.confirm` in danger style: "Se borrarán el audio y la transcripción de «name». No se puede deshacer." Removes the whole record (`sf.classes.remove`), list and totals update, focus goes to a sensible next element. Cancel or Escape deletes nothing.
6. Storage-full banner as in `classes-full.html`, shown in the list when a `storage:error` of kind full happened in this session, with the action to delete classes (the delete buttons are right there).
7. Wiring: text and names only via `textContent` and DOM nodes (never `innerHTML` with class names or transcript text). Delete the legacy pieces you replace.
